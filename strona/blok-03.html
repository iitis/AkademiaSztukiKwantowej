Kwantowy perceptron

Prowadzenie: dr hab. inż. Łukasz Pawela

Implementacja kwantowego modelu perceptronu na komputerach kwantowych IBM. Bramkowy model obliczeń kwantowych w praktyce: Qiskit, dostęp do IBM Quantum, szum kwantowy i mitygacja błędów pomiaru, kwantowe sieci neuronowe, algorytm Deutscha, bramki pulsowe.

Slajdy i skrypty (PDF)

Jak uruchomić ćwiczenia

  1. Zainstaluj Pythona w wersji 3.10 lub nowszej (python.org).
  2. Pobierz materiały bloku: przejdź do katalogu w repozytorium i użyj przycisku Code → Download ZIP (pobiera całe repozytorium) lub sklonuj je poleceniem git clone https://github.com/iitis/AkademiaSztukiKwantowej.git.
  3. Zainstaluj wymagane pakiety: pip install -r materialy/03-kwantowy-perceptron/warsztaty/requirements.txt
  4. Uruchom notatniki: jupyter notebook — a następnie otwórz wybrany plik .ipynb.
