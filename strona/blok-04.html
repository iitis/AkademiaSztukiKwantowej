Kwantowe wyżarzanie kombinatorycznych problemów optymalizacyjnych

Prowadzenie: dr hab. Bartłomiej Gardas

Adiabatyczne obliczenia kwantowe i algorytmy inspirowane fizyką, ze szczególnym uwzględnieniem procesora kwantowego D-Wave. Model Isinga i QUBO, kodowanie problemów (Max-Cut, kolorowanie grafów, TSP), symulowane wyżarzanie, symulowana bifurkacja, obliczenia na kartach graficznych.

Slajdy i skrypty (PDF)

Pliki otwierają się bezpośrednio w przeglądarce — nie trzeba niczego instalować ani zakładać konta.

Jak uruchomić ćwiczenia

  1. Zainstaluj Pythona w wersji 3.10 lub nowszej (python.org).
  2. Pobierz materiały bloku: przejdź do katalogu w repozytorium i użyj przycisku Code → Download ZIP (pobiera całe repozytorium) lub sklonuj je poleceniem git clone https://github.com/iitis/AkademiaSztukiKwantowej.git.
  3. Zainstaluj wymagane pakiety: pip install -r materialy/04-kwantowe-wyzarzanie/warsztaty/requirements.txt
  4. Uruchom notatniki: jupyter notebook — a następnie otwórz wybrany plik .ipynb.
