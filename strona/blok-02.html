Dwa dni z uczeniem maszynowym

Prowadzenie: dr hab. inż. Przemysław Głomb

Wprowadzenie do klasycznego (nie-kwantowego) uczenia maszynowego: analiza danych, klasteryzacja, redukcja wymiarowości, detekcja anomalii, maszyny wektorów nośnych, sieci neuronowe i konwolucyjne, duże modele językowe. Blok stanowi podstawę do metod kwantowych.

Jak uruchomić ćwiczenia

  1. Zainstaluj Pythona w wersji 3.10 lub nowszej (python.org).
  2. Pobierz materiały bloku: przejdź do katalogu w repozytorium i użyj przycisku Code → Download ZIP (pobiera całe repozytorium) lub sklonuj je poleceniem git clone https://github.com/iitis/AkademiaSztukiKwantowej.git.
  3. Zainstaluj wymagane pakiety: pip install -r materialy/02-uczenie-maszynowe/warsztaty/requirements.txt
  4. Uruchom notatniki: jupyter notebook — a następnie otwórz wybrany plik .ipynb.
